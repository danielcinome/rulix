# Configuration

Rulix is configured through `.rulix/config.json` in your project root.

## Default configuration

Running `rulix init` creates a config with these defaults:

```json
{
  "targets": [],
  "presets": [],
  "overrides": {},
  "options": {
    "tokenEstimation": "heuristic",
    "agentsMdHeader": true,
    "claudeMdStrategy": "concatenate",
    "syncOnSave": false
  }
}
```

## Fields

### `targets`

**Type**: `string[]`
**Default**: `[]`

List of adapter names to sync to. If empty, `rulix sync` exports to all available adapters.

```json
{
  "targets": ["cursor", "claude-code", "agents-md"]
}
```

Available adapters: `cursor`, `claude-code`, `agents-md`.

### `presets`

**Type**: `string[]`
**Default**: `[]`

> Planned for v0.2. Not yet implemented.

npm packages or local paths to reusable rule collections.

### `overrides`

**Type**: `Record<string, Partial<Rule>>`
**Default**: `{}`

> Planned for v0.2. Not yet implemented.

Override specific fields of preset rules by rule ID.

### `options`

#### `options.tokenEstimation`

**Type**: `"heuristic" | "tiktoken"`
**Default**: `"heuristic"`

How to estimate token counts for rules.

- `"heuristic"` — Lightweight estimation (~4 characters per token). No dependencies.
- `"tiktoken"` — Planned for v0.2. More accurate but requires additional dependency.

#### `options.agentsMdHeader`

**Type**: `boolean`
**Default**: `true`

When `true`, adds a `<!-- Generated by Rulix. Do not edit directly. -->` comment at the top of the generated `AGENTS.md` file.

#### `options.claudeMdStrategy`

**Type**: `"concatenate" | "reference"`
**Default**: `"concatenate"`

How to generate `CLAUDE.md`:

- `"concatenate"` — All `always` and `agent-selected` rules are combined into a single `CLAUDE.md` file, ordered by priority.
- `"reference"` — Planned for v0.2.

#### `options.syncOnSave`

**Type**: `boolean`
**Default**: `false`

> Planned for v0.2. Used by a future `rulix watch` command.

## Token budgets

Each adapter defines its own token budget based on the tool's known limits:

| Adapter | Max tokens | Max instructions | Warning threshold |
|---|---|---|---|
| Cursor | 10,000 | 500 | 80% |
| Claude Code | 2,000 | 150 | 80% |
| AGENTS.md | 32,768 | — | 80% |

Token budgets are checked by `rulix status` and `rulix validate`. When usage exceeds the warning threshold, a warning is displayed.

## File structure

```
.rulix/
├── config.json           # This file
└── rules/
    ├── typescript.md      # Rule files
    ├── testing.md
    └── security.md
```

Rules live in `.rulix/rules/*.md`. See [Writing Rules](writing-rules.md) for the rule format.
